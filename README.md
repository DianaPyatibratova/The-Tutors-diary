# Лабораторная работа №1

## Тема
Статическая клиентская часть веб-приложения

## Название проекта
**Дневник репетитора**

## Цель работы
Цельработы: Научиться создавать простую веб-страницу, использовать HTML для структуры сайта и CSS для его оформления, а также познакомиться с Flexbox, CSS Grid и адаптивной версткой.

## Идея проекта
Для лабораторной работы был выбран сайт для репетитора.

Основная идея проекта — хранить в одном месте информацию об учениках и домашних заданиях, расписание и т.д.

На данном этапе сайт является статическим. В дальнейшем его можно будет расширить: добавить расписание занятий, оплату, записи уроков, загрузку материалов и другие функции.

## Структура проекта
В проекте были созданы следующие файлы:
    web-project/
    ├── index.html
    ├── styles/
    │   └── main.css
    └── README.md

## Ход работы

### 1. Создание HTML-страницы
Сначала был создан основной файл `index.html`.

В нем была задана стандартная структура HTML-документа, указан русский язык страницы, подключена кодировка UTF-8 и добавлены настройки для корректного отображения сайта на мобильных устройствах.

Также к HTML-странице был подключен отдельный CSS-файл.

### 2. Создание шапки сайта
В верхней части страницы была создана шапка сайта.

В ней размещены:
- название проекта «Дневник репетитора»;
- навигационная ссылка на раздел с учениками.

### 3. Создание главного блока
После шапки был добавлен главный информационный блок, чтобы пользователь сразу понимал назначение сайта.

В нем размещены:
- название сайта;
- краткое описание;
- кнопка перехода к списку учеников.

### 4. Создание формы поиска
Далее была создана форма для поиска и фильтрации учеников, но она пока что не выполняет реальную функцию.

В форме есть:
- поле для ввода имени ученика;
- выпадающий список с выбором предмета;
- кнопка поиска.

### 5. Создание карточек учеников
Основной частью страницы стали 6 карточек учеников.

В каждой карточке указывается:
- имя ученика;
- класс;
- цель занятий;
- предмет;
- статус домашнего задания.

Для каждой карточки также добавлен круглый визуальный элемент с первой буквой имени ученика.

### 6. Оформление страницы
Для оформления сайта был создан отдельный CSS-файл.

С помощью CSS были настроены:
- цвета;
- шрифты;
- размеры текста;
- отступы;
- рамки;
- закругленные углы;
- кнопки;
- карточки;
- расположение элементов.

Для сайта была выбрана теплая бежево-коричневая цветовая гамма.

### 7. Использование Flexbox
Flexbox использовался для расположения элементов в одну строку.

Он применялся:
- в шапке сайта;
- в форме поиска;
- внутри карточек учеников.

Это позволило удобно выравнивать элементы относительно друг друга.

### 8. Использование CSS Grid
CSS Grid использовался для размещения карточек учеников.

На большом экране карточки располагаются по 3 в строке.

Такой способ размещения был выбран, потому что карточки образуют сетку.

### 9. Создание адаптивной верстки
Для того чтобы сайт нормально отображался на разных устройствах, была добавлена адаптивная верстка.

При уменьшении ширины экрана количество карточек в строке меняется:
- на большом экране — 3 карточки;
- на планшете — 2 карточки;
- на телефоне — 1 карточка.

### 10. Создание дополнительного блока
В нижней части страницы был добавлен раздел «О проекте».

В нем кратко описывается назначение сайта и его основная идея.

### 11. Создание подвала
В самом низу страницы был добавлен footer сайта.

В нем размещено название проекта и год.

Footer оформлен в более темном цвете, чтобы визуально отделить его от основной части страницы.

## Результат
В результате выполнения лабораторной работы была создана статическая адаптивная веб-страница «Дневник репетитора».

На странице реализованы:
- шапка сайта;
- навигация;
- главный информационный блок;
- форма поиска и фильтрации;
- 6 карточек учеников;
- дополнительный информационный блок;
- Footer;
- адаптивная верстка.

## Вывод
В ходе выполнения лабораторной работы были изучены основы HTML и CSS. Также были освоены семантические элементы HTML, работа с формами, Flexbox, CSS Grid и адаптивная верстка.
