# Дневник репетитора - Лабораторная работа №3

## Тема работы

Backend с REST API и базой данных.

## Цель работы

Создать backend для веб-приложения, реализовать REST API, подключить базу данных и связать frontend с backend через HTTP-запросы.

## Описание проекта

**Дневник репетитора** — веб-приложение для хранения информации об учениках, предметах, целях занятий и домашних заданиях.

В лабораторной работе №3 приложение было переведено на клиент-серверную архитектуру.

Теперь:

- frontend отвечает за отображение данных;
- backend обрабатывает запросы;
- данные хранятся в базе SQLite;
- обмен между frontend и backend выполняется через REST API.

## Основная сущность

Основная сущность проекта — **ученик (`Student`)**.

Поля сущности:

- `id` — уникальный идентификатор;
- `name` — имя ученика;
- `class_number` — класс;
- `subject` — предмет;
- `description` — цель занятий;
- `homework` — статус домашнего задания;
- `created_at` — дата создания записи.

## REST API

В проекте реализованы CRUD-операции для сущности `Student`.

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/students` | Получить список учеников |
| `POST` | `/api/students` | Добавить нового ученика |
| `GET` | `/api/students/{student_id}` | Получить ученика по id |
| `PATCH` | `/api/students/{student_id}` | Изменить данные ученика |
| `DELETE` | `/api/students/{student_id}` | Удалить ученика |

## Пример создания ученика

Запрос:

```http
POST /api/students
```

Тело запроса:

```json
{
  "name": "Иван",
  "class_number": 9,
  "subject": "Физика",
  "description": "Подготовка к ОГЭ",
  "homework": "Задано"
}
```

При успешном создании сервер возвращает статус:

```text
201 Created
```

## Пример изменения ученика

Для частичного изменения используется метод `PATCH`.

Например, изменение статуса домашнего задания:

```json
{
  "homework": "Выполнено"
}
```

## Пример удаления ученика

```http
DELETE /api/students/1
```

При успешном удалении сервер возвращает:

```text
204 No Content
```

## База данных

Для хранения данных используется **SQLite**.

В базе создаётся таблица `students`.

Для полей используются ограничения:

- `id` — первичный ключ;
- обязательные поля не могут быть пустыми;
- `class_number` должен быть от 1 до 11;
- `homework` может принимать только допустимые значения.

Файл базы данных создаётся автоматически при запуске backend.

## Валидация

Для проверки входящих данных используется **Pydantic**.

Созданы схемы:

- `StudentCreate` — создание ученика;
- `StudentUpdate` — изменение ученика;
- `StudentResponse` — данные, возвращаемые сервером.

## Работа frontend с backend

Frontend получает данные с backend с помощью функции `fetch()`.

Адрес API:

```javascript
const API_URL = 'http://127.0.0.1:8000/api/students';
```

При загрузке страницы отправляется запрос:

```http
GET /api/students
```

Полученные данные отображаются в карточках учеников.

## Добавление ученика

После заполнения формы frontend отправляет:

```http
POST /api/students
```

Данные передаются в формате JSON.

После успешного добавления список учеников загружается заново.

## Изменение ученика

Статус домашнего задания можно изменить прямо в карточке ученика.

При изменении выполняется:

```http
PATCH /api/students/{student_id}
```

## Удаление ученика

В правом верхнем углу карточки находится крестик `×`.

Перед удалением появляется подтверждение.

После подтверждения выполняется:

```http
DELETE /api/students/{student_id}
```

После успешного удаления карточка исчезает со страницы.

## Запуск backend

Перейти в папку backend:

```bash
cd backend
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение:

```bash
.venv\Scripts\activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить backend:

```bash
python -m uvicorn app.main:app --reload
```

Backend будет доступен по адресу:

```text
http://127.0.0.1:8000
```

## Запуск frontend

Открыть второй терминал и перейти в папку frontend:

```bash
cd frontend
```

Запустить локальный сервер:

```bash
python -m http.server 5500
```

Открыть в браузере:

```text
http://127.0.0.1:5500
```
